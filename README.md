an abandoned roblox project of mine. feel free to use it, but give credit (MIT).

this project focuses on the chassis. it's mostly related to [VitaVehicle](https://github.com/jreo03/g-rcp2) in terms of handling. keep in mind that i've left this in the shelf for so long that i forgot what most of the code looks like, so any guidance is not gauranteed. i suggest you play around with it.

what i do remember, is using external parts to act as variables in order to try syncing with the ever inconsistent physics engine.

# scaling:
- a meter is 3.9057617797775266 studs.
- gravity is supposedly 38.27646544181977 studs/s² yet it's 38.606. i don't remember exactly what i went through to get that value.
# issue:
since roblox filters out audio that aren't owned by you, pretty much everything is silent. if you want to know what everything sounded like, refer to [this video](https://video.twimg.com/ext_tw_video/1890828929625419776/pu/vid/avc1/1276x720/h1VlNSFfjhNIUhXa.mp4). the car uses a similar system i have with VitaVehicle as well, so if you wish to restore the engine sounds, check out [my soundpacks](https://jreo.itch.io/jreo-sva) and upload them to roblox, **but please lower their volumes to avoid roblox's moderation, and be weary about spamming uploads.**
